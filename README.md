
# Sistema de Controle de Pedidos — Masseiras do Sertão

## Sobre o projeto
Projeto acadêmico desenvolvido na disciplina de Projeto de Software para apoiar a organização das encomendas da Masseiras do Sertão, empreendimento localizado em Juazeiro, Bahia.

## Objetivo
Facilitar o cadastro de clientes, produtos e pedidos, além da consulta de encomendas, datas de entrega e acompanhamento da situação dos pedidos.

## Funcionalidades planejadas
- Cadastro de clientes.
- Cadastro de produtos.
- Registro de encomendas.
- Consulta de pedidos.
- Atualização da situação: Pendente, Em preparação e Concluído.

## Tecnologias previstas
- Java 21
- Spring Boot
- HTML5, CSS3 e Thymeleaf
- PostgreSQL
- Git e GitHub

## Situação do projeto
Em desenvolvimento. As funcionalidades descritas ainda serão implementadas e testadas.
